# Votación del uniforme · Ginecología y Obstetricia · Hospital Distrital de Laredo

Página pública para votar entre tres uniformes finalistas (1, 6 y 10). Un voto por persona, resultados en vivo.

Los votos se guardan en Supabase mediante dos funciones (`emitir_voto_uniforme` y `resultados_uniformes`). La tabla no es accesible directamente.
